# Pooja Prabhu — Developer Portfolio Website

A fast, responsive, and accessible personal developer portfolio built with pure **HTML5, CSS3, and JavaScript**. Designed with a **Modern Developer Portfolio** aesthetic using an **Orange & Charcoal** color system.

Built specifically for **Pooja Prabhu**, First-Year Master of Computer Applications (MCA) student at **Poornaprajna Institute of Management (PIM)**, Udupi, Karnataka.

---

## 🌟 Key Highlights & Features

- **Orange & Charcoal Theme:** Custom design system with tailored light mode (default) and dark mode.
- **Faithful Skill Expertise Representation:** Programming languages (C, C++, Java, Python, JavaScript, R, HTML, CSS, SQL) are accurately portrayed with self-evaluated `Basic` badges and 5-step visual meters without exaggeration.
- **Text-Focused Hero Section:** Features the strong headline *"First year MCA student"*, location badge (*Udupi, Karnataka*), elevator pitch, call-to-actions, and an interactive JSON terminal preview.
- **Academic Education Timeline:** Detailed entries for Master of Computer Applications (MCA) at PIM Udupi (2026–2028, Pursuing) and Bachelor of Science (B.Sc.) at Poornaprajna College (2023–2026, Completed).
- **Featured Real Project:** *Knowledge Management System* (Web Development, Completed) with interactive architecture breakdown modal and tech pills.
- **Work Experience & Certifications:** Full Stack experience at *nextsync* (2026–Present), Full Stack certification from *evolve tech* (2026), and *Youth Red Cross* volunteering.
- **Interactive Resume Modal & Print Engine:** Click **"Resume"** to open a printable resume formatted with dedicated `@media print` rules for clean single/two-page PDF export.
- **Direct Contact System:** 1-click **Copy Email** (`poojaprabhujan23@gmail.com`) with toast notification, direct `mailto:` form dispatcher, and verified GitHub link.
- **Responsive Mobile Navigation:** Slide-out drawer navigation with accessible ARIA tags and backdrop overlay.
- **Zero Dependencies:** Pure vanilla HTML, CSS, and JS — no node modules, build steps, or external framework runtime needed.

## 🌐 Deploy to GitHub Pages (Free)

Since this project uses pure HTML, CSS, and JavaScript, it can be deployed to **GitHub Pages** in under 2 minutes:
1. Push this folder to your GitHub repository: [`poojaprabhujan23-blip`](https://github.com/poojaprabhujan23-blip).
2. On GitHub, navigate to **Settings > Pages**.
3. Under **Build and deployment > Source**, select `Deploy from a branch`.
4. Choose the `main` (or `master`) branch and root `/` folder, then click **Save**.
5. Your live portfolio URL will be ready at: `https://poojaprabhujan23-blip.github.io/portfolio/`.
